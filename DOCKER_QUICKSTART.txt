📦 QAMS Web - Estructura Docker
================================

📁 Proyecto
├── 📄 Dockerfile                    ← Build para producción (Node → Nginx)

├── 📄 .env.docker                   ← Variables de ambiente

├── 📄 docker.bat                    ← Script gestión (Windows)

├── 📁 .github/workflows

📍 PRODUCCIÓN (Nginx)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  # Windows
  docker.bat start
  docker.bat logs
  docker.bat stop

  # Linux/Mac
  ./docker.sh start
  ./docker.sh logs
  ./docker.sh stop

  # Docker Compose directo
  docker-compose up -d
  docker-compose logs -f
  docker-compose down

🏗️ ARQUITECTURA
═══════════════════════════════════════════════════════════

PRODUCCIÓN (Multi-stage):

  ┌─────────────────────────────────────┐
  │  Stage 1: Builder (Node 20)         │
  │  - npm install                      │
  │  - npm run build                    │
  │  - Genera /dist                     │
  │  (Descartado en imagen final)       │
  └──────────────────┬──────────────────┘
                     │
                     ↓
  ┌─────────────────────────────────────┐
  │  Stage 2: Runtime (Nginx Alpine)    │
  │  - COPY --from=builder /dist        │
  │  - Sirve archivos estáticos         │
  │  - Imagen final: ~100MB             │
  │  - Puerto: 80                       │
  └─────────────────────────────────────┘

DESARROLLO (Single-stage):

  ┌─────────────────────────────────────┐
  │  Node 20 Alpine                     │
  │  - npm install                      │
  │  - npm start (ng serve)             │
  │  - Hot reload habilitado            │
  │  - CHOKIDAR_USEPOLLING=true         │
  │  - Puerto: 4200                     │
  │  - Volúmenes: ./src → /app/src      │
  └─────────────────────────────────────┘

🎯 CASOS DE USO
═══════════════════════════════════════════════════════════

LOCAL (sin Docker):
  npm install && npm start
  → http://localhost:4200

DESARROLLO (con Docker):
  docker-compose -f docker-compose.dev.yml up
  → http://localhost:4200 (con hot reload)

PRODUCCIÓN (con Docker):
  docker-compose up -d
  → http://localhost

CI/CD (Automático):
  GitHub Actions / GitLab CI
  → Build, Test, Push, Deploy

💡 TIPS
═══════════════════════════════════════════════════════════

1. Ver logs en tiempo real:
   docker-compose logs -f qams-web

2. Ejecutar comandos en contenedor:
   docker-compose exec qams-web sh

3. Reconstruir sin caché:
   docker-compose build --no-cache

4. Limpiar todo:
   docker-compose down -v

5. Ver tamaño de imagen:
   docker images | grep qams-web

6. Cambiar puerto (Puerto 8080):
   Edita docker-compose.yml:
   ports:
     - "8080:80"
